# precut — 프리미어 프로 자동 컷편집 도구

영상 하나를 넣으면 **무음 구간을 자연스럽게 잘라내고**, **구간별 소리 밸런스를 맞추고**,
**자막까지 만들어서** 프리미어 프로에서 바로 열 수 있는 시퀀스로 내보냅니다.

렌더링된 완성본이 아니라 **편집 가능한 타임라인**을 만들어 주는 게 핵심입니다.
컷은 이미 다 나뉘어 있고 오디오 레벨도 잡혀 있으니, 프리미어에서는 다듬는 일만 하면 됩니다.

```
원본 영상 ──▶ 무음 분석 ──▶ 컷 정리 ──▶ 라우드니스 측정 ──▶ 음성 인식
                                                              │
        프리미어에서 여는 .xml  ◀── 시퀀스 생성 ◀──────────────┘
        타임라인용 .srt 자막
```

## 무엇을 해주나요

**1. 무음 컷편집 — 자연스럽게**

단순히 소리 없는 곳을 다 잘라내면 말이 뚝뚝 끊깁니다. precut은 이렇게 다듬습니다.

- **자동 임계값**: 녹음마다 다른 잡음 바닥을 측정해서 무음 기준을 스스로 정합니다.
- **히스테리시스**: 기준선 근처에서 소리가 오르내려도 컷이 잘게 쪼개지지 않습니다.
- **앞뒤 여유(lead-in/out)**: 말이 시작되기 조금 전부터, 끝난 뒤 조금까지 남겨서 첫 자음과 어미가 잘리지 않습니다.
- **최소 무음 길이**: 짧은 숨·띄어쓰기는 자르지 않습니다. 말의 리듬이 유지됩니다.
- **크로스페이드**: 컷 지점마다 잘라낸 무음을 이용해 짧은 오디오 크로스페이드를 걸어 '툭' 하는 소리를 없앱니다.

**2. 소리 밸런스**

- EBU R128(방송 라우드니스 표준)로 컷마다 실제 체감 음량을 측정합니다.
- 컷들의 **가중 중앙값**을 기준으로 삼아, 작게 말한 구간은 올리고 크게 말한 구간은 내립니다.
- 보정량은 XML에 **클립별 오디오 레벨**로 들어가므로, 프리미어에서 언제든 다시 만질 수 있습니다.
- 보정 강도(`--balance-strength`)로 자연스러움과 균일함 사이를 조절합니다. 1.0은 완전 균일, 0.5는 절반만 보정.

**3. 자막**

- Whisper로 음성을 인식해 **컷 편집된 타임라인 기준**의 SRT를 만듭니다. 잘려나간 구간의 말은 자동으로 빠집니다.
- 한국어 자막 규칙을 지킵니다: 한 줄 글자 수 제한, 최대 2줄, 두 줄 길이 균형 맞춤, 최소 노출 시간, 읽기 속도(CPS) 상한.
- 문장이 끝나는 지점(`~습니다`, `~요`, 마침표 등)과 말이 쉬는 지점에서 자막을 끊습니다.

> 음성 인식은 전체 과정에서 **가장 오래 걸리는 단계**입니다. 그래픽카드 없이 10분짜리 영상을
> `small` 모델로 처리하면 3~8분, `medium` 은 8~20분 정도 걸립니다. 진행률이 표시되니
> 멈춘 게 아닌지 걱정하지 않으셔도 됩니다. 처음 한 번은 모델을 내려받는 시간이 더 붙습니다.
> 명령줄 기본값은 `medium`(정확도 우선)이고, 윈도우 실행 도우미는 `small`(속도 우선)로 물어봅니다.

## 설치

Python 3.10 이상과 ffmpeg가 필요합니다.

**윈도우** — 명령어를 몰라도 됩니다.

1. 저장소를 ZIP으로 받아 압축을 풉니다.
2. 폴더 안에서 **`1-설치하기`** 파일을 찾습니다.
   ZIP은 같은 이름의 폴더가 이중으로 만들어지는 경우가 많으니, 이 파일이 보일 때까지 폴더를 계속 들어가세요.
   `1-설치하기`·`2-영상처리하기`·`README.md`·`precut` 폴더가 **함께** 보이면 그 위치가 맞습니다.
   (`precut` 폴더 안으로는 들어가지 마세요)
3. **`1-설치하기` 를 더블클릭**합니다.
4. 설치가 끝나면 **`2-영상처리하기` 를 더블클릭**하고, 영상 경로를 물어볼 때 파일이나 폴더를 창으로 끌어다 놓으면 됩니다.
   폴더를 넣으면 **하나로 이어붙일지, 각각 따로 편집할지** 물어봅니다.

무엇이 잘못됐는지 모르겠으면 **`3-상태확인하기`** 를 실행하세요.
설치 상태와 최근 실행 기록을 한 화면에 보여줍니다.
모든 실행 내용은 같은 폴더의 `precut-log.txt` 에도 기록되므로, 창이 닫혀도 나중에 확인할 수 있습니다.

`.ps1` 파일을 직접 실행해도 되지만, 실행 정책이나 창이 바로 닫히는 문제를 피하려면 위 `.bat` 파일을 쓰세요.

명령줄을 쓰고 싶다면:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-windows.ps1
```

## 사용법

```bash
precut 인터뷰.mp4              # 파일 하나
precut ./촬영본                 # 폴더 안의 영상을 각각 따로 편집
precut ./촬영본 --merge         # 폴더 안의 영상을 하나의 시퀀스로 이어붙이기
```

`인터뷰_precut/` 폴더에 결과가 생깁니다.

| 파일 | 내용 |
|---|---|
| `인터뷰.xml` | **프리미어에서 가져올 시퀀스** (컷 + 오디오 레벨 + 크로스페이드) |
| `인터뷰.srt` | 컷 편집된 타임라인에 맞춘 자막 |
| `인터뷰_import.jsx` | 위 두 개를 한 번에 불러오는 프리미어 스크립트 |
| `인터뷰_report.json` | 컷 목록, 구간별 라우드니스와 보정값 |

### 여러 영상을 하나로 이어붙이기

`--merge` (또는 `-m`) 를 붙이면 영상들이 **순서대로 이어진 시퀀스 하나**가 만들어집니다.
파일 이름의 숫자를 숫자로 비교해 정렬하므로 `영상2` 가 `영상10` 보다 앞에 옵니다.

```bash
precut ./촬영본 --merge
precut 1부.mp4 2부.mp4 3부.mp4 --merge --sequence-name "완성본"
```

이어붙일 때는 **소리 밸런스도 영상들을 통틀어 한 기준으로** 맞춥니다.
따로 편집하면 각 영상 안에서만 균형이 잡혀 영상이 바뀔 때 음량이 튀지만,
이어붙이면 작게 녹음된 영상 전체가 함께 올라가서 이어 들어도 음량이 고릅니다.

컷 사이 크로스페이드는 **같은 영상 안에서만** 걸립니다. 영상이 바뀌는 지점은
잘라낼 여유가 없으므로 하드컷으로 두고, 필요하면 프리미어에서 직접 트랜지션을 넣으면 됩니다.

> 이어붙이기와 `--render-preview`·`--render-audio` 는 함께 쓸 수 없습니다.
> 미리보기 렌더링은 원본 하나를 다시 인코딩하는 방식이라서, 이때는 XML을 프리미어에서 열어 확인하세요.

### 목표 길이에 맞춰 자르기

`-t` (또는 `--target-duration`) 로 원하는 길이를 주면, 거기에 맞도록 무음 기준을
자동으로 조절합니다. 임계값을 손으로 더듬을 필요가 없습니다.

```bash
precut ./촬영본 --merge -t 30m      # 30분에 맞추기
precut 강의.mp4 -t 1h20m
```

임계값을 올릴수록 더 많은 소리가 무음으로 판정되어 결과가 짧아집니다. 이분 탐색으로
목표에 가장 가까운 값을 찾고, 임계값만으로 부족하면 앞뒤 여유와 최소 무음 길이까지
단계적으로 줄입니다. 마지막 단계에서는 오히려 최소 컷 길이를 늘려서, 잘게 튀는
조각들이 사라지고 결과가 보기 편해지도록 합니다.

오디오는 이미 분석해 둔 것을 다시 훑기만 하므로 추가 시간은 몇 초뿐입니다.

> 목표가 너무 짧으면 **소리가 큰 구간만 남습니다.** 말이 60분 들어 있는 소재를
> 30분으로 맞추면 말의 절반이 잘려나간다는 뜻입니다. 도달할 수 없는 목표를 주면
> 한계치와 함께 경고를 띄우니, 그 숫자를 보고 판단하시면 됩니다.

### 프리미어에서 열기

**방법 A — 스크립트 (한 번에)**

프리미어에서 `파일 > 스크립트 > 스크립트 파일 실행...` 으로 `*_import.jsx` 를 선택하면
XML과 자막을 가져오고 시퀀스까지 열어줍니다.

**방법 B — 직접 가져오기**

1. `파일 > 가져오기` 로 `.xml` 선택 → 프로젝트 패널에 시퀀스가 생깁니다.
2. 시퀀스를 더블클릭해서 타임라인을 엽니다.
3. `.srt` 를 가져와 타임라인 위로 끌어놓으면 캡션 트랙이 됩니다.
   (`창 > 캡션 및 그래픽` 에서 글꼴·위치를 한 번에 바꿀 수 있습니다.)

> 원본 파일을 옮기거나 이름을 바꾸면 XML이 미디어를 못 찾습니다.
> 그때는 프리미어가 띄우는 '미디어 연결' 창에서 파일을 다시 지정하면 됩니다.

### 자주 쓰는 명령

```bash
# 영상 유형에 맞는 프리셋
precut 브이로그.mp4 -p vlog
precut 강의.mp4 -p lecture
precut 팟캐스트.wav -p podcast

# 컷만, 자막 없이 (빠름)
precut 인터뷰.mp4 --no-subtitles

# 얼마나 잘릴지 먼저 확인 (파일을 만들지 않음)
precut 인터뷰.mp4 --dry-run --no-subtitles

# 확인용 미리보기 영상까지 렌더링 (자막 굽기 포함)
precut 인터뷰.mp4 --render-preview --burn-subtitles

# 컷을 더 촘촘하게 / 더 여유 있게
precut 인터뷰.mp4 -p tight
precut 인터뷰.mp4 -p gentle

# 무음 기준을 직접 지정
precut 인터뷰.mp4 --threshold-db -42 --min-silence 0.6

# 여러 파일 · 폴더 한꺼번에
precut *.mp4 --no-subtitles -o ./편집본
precut "C:\Users\USER\Desktop\영상2" --no-subtitles
```

### 프리셋

| 프리셋 | 앞여유/뒤여유 | 최소 무음 | 성격 |
|---|---|---|---|
| `talking-head` (기본) | 0.12 / 0.22초 | 0.45초 | 인터뷰·강좌 등 말하는 영상 |
| `vlog` | 0.18 / 0.30초 | 0.60초 | 현장음이 있는 브이로그 |
| `lecture` | 0.20 / 0.35초 | 0.90초 | 긴 강의. 무음을 0.35초 남겨 호흡 유지 |
| `podcast` | 0.15 / 0.25초 | 0.70초 | 오디오 중심. 밸런스 강하게 |
| `tight` | 0.06 / 0.12초 | 0.25초 | 최대한 짧게. 숏폼용 |
| `gentle` | 0.25 / 0.40초 | 1.20초 | 확실한 무음만 제거 |

### 주요 옵션

```
컷 편집
  --threshold-db DB      무음 판정 기준(dBFS). 기본은 자동
  --lead-in SEC          말 시작 앞 여유
  --lead-out SEC         말 끝 뒤 여유
  --min-silence SEC      이보다 짧은 무음은 자르지 않음
  --min-clip SEC         이보다 짧은 컷은 버림
  --keep-silence SEC     무음을 완전히 없애지 않고 이만큼 남김
  --audio-transition N   오디오 크로스페이드 프레임 (기본 4)
  --video-transition N   영상 디졸브 프레임 (기본 0 = 하드컷)
  --no-transitions       트랜지션 없이 전부 하드컷

소리 밸런스
  --no-balance           구간별 볼륨 보정 끄기
  --balance-strength 0~1 보정 강도 (기본 0.75)
  --balance-reference    program(컷들의 중앙값) | target(절대 목표값)
  --balance-target LUFS  목표 라우드니스
  --max-boost / --max-cut  최대 증폭/감쇠 (dB)

자막
  --no-subtitles         자막 생성 건너뛰기
  --model NAME           Whisper 모델 (tiny/base/small/medium/large-v3)
  --language CODE        언어 (기본 ko, 자동감지는 auto)
  --device cpu|cuda      실행 장치
  --chars-per-line N     한 줄 최대 글자 수 (기본 20)
  --max-cps N            초당 최대 글자 수 (기본 11)

출력
  -t, --target-duration  목표 길이에 맞춰 자동으로 더 잘라냄 (30m, 1h20m, 1:30:00)
  -m, --merge            여러 영상을 하나의 시퀀스로 이어붙임
  --sequence-name NAME   시퀀스 이름
  -o, --outdir DIR       결과 폴더
  --edl / --vtt          EDL·WebVTT도 함께 출력
  --render-preview       확인용 mp4 렌더링
  --render-audio         정규화된 오디오(WAV) 렌더링
  --burn-subtitles       미리보기에 자막 굽기
  --dry-run              파일을 쓰지 않고 결과만 출력
  --json                 결과를 JSON으로 출력
```

전체 목록은 `precut --help`.

### 설정 파일

반복해서 쓰는 값은 JSON으로 저장해 두고 `-c` 로 불러옵니다. 프리셋 위에 덮어씌워집니다.

```bash
precut 인터뷰.mp4 -c 내설정.json
```

```json
{
  "shape":     { "lead_in": 0.15, "lead_out": 0.25, "min_silence": 0.5 },
  "balance":   { "strength": 0.8, "max_boost_db": 10.0 },
  "subtitles": { "max_chars_per_line": 18, "max_cps": 10.0 },
  "transcribe": { "model": "large-v3", "language": "ko" },
  "xml":       { "audio_transition_frames": 5 }
}
```

`config.example.json` 에 전체 항목이 주석과 함께 정리되어 있습니다.

## 동작 방식

1. **분석용 오디오 추출** — 16kHz 모노 WAV.
2. **엔벨로프 계산** — 10ms 간격, 30ms 창의 RMS를 dBFS로.
3. **임계값 결정** — 하위 12% 백분위를 잡음 바닥, 상위 88%를 발화 레벨로 보고 그 사이에서 기준을 잡습니다.
4. **구간 검출** — 여는 기준(`+히스테리시스`)과 닫는 기준을 따로 둔 상태머신으로 발화 구간을 뽑고, 잡음 바닥 근처까지 앞뒤로 되짚어 약한 자음까지 포함시킵니다.
5. **컷 정리** — 여유 추가 → 짧은 무음 병합 → 짧은 컷 제거 → 프레임 격자에 정렬.
6. **라우드니스** — ffmpeg `ebur128`로 순간 라우드니스를 수집하고, 컷마다 게이팅 적용 에너지 평균을 냅니다.
7. **자막** — Whisper 단어 타임스탬프를 컷 타임라인으로 옮기고 읽기 규칙에 맞춰 다시 묶습니다.
8. **내보내기** — FCP7 XML(xmeml v4), SRT, 프리미어 스크립트.

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 너무 많이 잘림 | `--threshold-db` 를 더 낮게(예: -50), `--min-silence` 를 크게 |
| 무음이 안 잘림 | `--threshold-db` 를 더 높게(예: -35), 또는 `-p tight` |
| 말 끝이 잘림 | `--lead-out 0.4` 처럼 뒤 여유를 늘리세요 |
| 컷이 딱딱함 | `--audio-transition 8`, 또는 `--video-transition 4` 로 디졸브 추가 |
| XML 가져오기 실패 | `--no-transitions` 로 다시 만들어 보세요 |
| 볼륨이 널뛰기함 | `--balance-strength 0.5` 로 보정을 약하게 |
| 자막이 너무 빨리 지나감 | `--max-cps 9 --chars-per-line 16` |
| 음성 인식이 느림 | `--model small`, GPU가 있으면 `--device cuda` |
| 음성 인식에서 멈춘 것 같음 | 정상입니다. 가장 오래 걸리는 단계이며 진행률이 표시됩니다 |
| 영상마다 따로 만들어짐 | `--merge` 를 붙이거나, 실행 도우미에서 "하나로 이어붙이기" 선택 |
| 영상이 바뀔 때 음량이 튐 | `--merge` 로 처리하면 영상 간 음량까지 맞춰집니다 |
| 결과가 너무 김 | `-t 30m` 처럼 목표 길이를 주면 알아서 맞춥니다 |
| 프리미어에서 미디어 오프라인 | 클립 우클릭 → 미디어 연결. 원본을 옮겼거나 이름이 바뀐 경우입니다 |

## 개발

```bash
pip install -e ".[dev]"
pytest
```

테스트는 순수 로직(무음 검출·컷 정리·자막 규칙·XML 구조)과, ffmpeg로 생성한 샘플 영상을
실제로 처리하는 통합 테스트로 나뉩니다. ffmpeg가 없으면 통합 테스트는 자동으로 건너뜁니다.

```
precut/
├─ audio.py       WAV 로딩, dBFS 엔벨로프
├─ silence.py     임계값 결정, 발화 구간 검출
├─ segments.py    컷 정리, 원본↔타임라인 시간 변환
├─ loudness.py    EBU R128 측정, 구간별 게인 계산
├─ transcribe.py  Whisper 래퍼
├─ subtitles.py   자막 큐 생성, 줄바꿈, SRT/VTT
├─ timeline.py    여러 원본을 한 시퀀스에 배치
├─ render.py      ffmpeg 미리보기·오디오 렌더링
├─ pipeline.py    전체 흐름
└─ exporters/     FCP7 XML · EDL · 프리미어 스크립트
```
